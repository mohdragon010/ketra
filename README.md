# Ketra – Study Dashboard

Ketra is a study dashboard designed to help students organize subjects, manage tasks, take notes, and stay motivated in one place.

## Features
- Subjects system with custom colors and icons
- Task management per subject (create, edit, delete, complete)
- Progress tracking for subjects
- Notes page with a rich text editor
- Quotes page using an external API
- Downloadable quote images
- Modern dialogs and UI interactions
- Light and dark mode support

## Tech Stack
- Next.js
- React
- Tailwind CSS
- Zustand
- shadcn/ui
- MUI
- Tiptap
